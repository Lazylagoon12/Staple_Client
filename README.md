<h1 align="center">Staple Client</h1>
<p align="center">A Minecraft Fabric utility client fork focused on customization and anarchy-server gameplay.</p>

<div align="center">
  <a href="https://github.com/Lazylagoon12/Staple_Client">GitHub Repository</a>
</div>

## Building
- Clone this repository.
- Run `./gradlew build`.

## Installation
Build the project and place the resulting client JAR in your Fabric mods folder.
